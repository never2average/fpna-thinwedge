# @thinwedge/thinwedge-responses-api-proxy

<p align="center"><code>npm i -g @thinwedge/thinwedge-responses-api-proxy</code> to install <code>thinwedge-responses-api-proxy</code></p>

This package distributes the prebuilt [ThinWedge Responses API proxy binary](https://github.com/thinwedge/thinwedge/tree/main/thinwedge-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/thinwedge-responses-api-proxy.js --help
```

Refer to [`thinwedge-rs/responses-api-proxy/README.md`](https://github.com/thinwedge/thinwedge/blob/main/thinwedge-rs/responses-api-proxy/README.md) for detailed documentation.
